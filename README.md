# Кинотеатр

Курсовой проект по МДК 01.01 «Разработка программных модулей». Система автоматизирует бронирование и продажу билетов, ведение афиши и расписания кинотеатра. Веб-интерфейсы персонала и клиент для Windows и Android работают с общим сервером и базой данных.

## Возможности

- **Клиент:** поиск фильмов, выбор сеанса и мест, бронь на 10 минут, учебная покупка, QR-билеты, история заказов и личный кабинет.
- **Кассир:** продажа билетов, печать и сохранение билетов, проверка QR-кодов и оформление возвратов.
- **Администратор:** управление фильмами, жанрами, залами, местами и расписанием, отмена сеансов, работа с заказами и отчётами.
- **Суперпользователь:** управление учётными записями, ролями и доступом сотрудников.

Оплата демонстрационная: деньги не списываются, данные карты не запрашиваются. Письма сохраняются локально после запуска команды `send_notifications`. Можно использовать вымышленные почтовые адреса.

## Технологии и структура

Python, Django 5.2, Django REST Framework, SQLite и Flet. Сервер проверяет права доступа, рассчитывает цены и защищает места от двойной продажи.

- `accounts`, `catalog`, `bookings` — пользователи, каталог, бронирование и билеты.
- `cashier`, `staff` — веб-касса и управление кинотеатром.
- `reports`, `notifications` — отчёты и уведомления.
- `client/src` — клиент для Windows и Android.
- `tests` — автоматические тесты, `docs` — документация.

Код разделён по обязанностям: проверка ввода, бизнес-операции и интерфейсы находятся в отдельных модулях. Расчёт цены и учебная оплата используют небольшие интерфейсы в соответствии с принципами SOLID.

## Запуск в Windows

При первом запуске подготовьте окружение и базу:

```powershell
cd C:\Cinema
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
```

Запустите сервер и оставьте окно открытым:

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

- Касса: <http://127.0.0.1:8000/cashier/>.
- Управление: <http://127.0.0.1:8000/staff/> — стартовая страница зависит от роли.
- Техническая панель Django: <http://127.0.0.1:8000/admin/>.
- REST API: <http://127.0.0.1:8000/api/v1/>.

Учётные записи сотрудников создаёт суперпользователь. Для запуска десктопного клиента откройте `start-client.cmd` в отдельном окне. Сервер должен продолжать работать.

APK для Android: `dist/cinema.apk`. На телефоне укажите в настройках приложения адрес API компьютера в общей Wi-Fi сети. Сервер должен принимать подключения из локальной сети.

## Тестирование и документация

```powershell
.\.venv\Scripts\python.exe manage.py test tests --noinput
```

Тесты проверяют бронирование, цены, оплату, возвраты, права доступа, QR-билеты, API и клиент. Они используют отдельную тестовую базу.

Параметры окружения перечислены в `.env.example`.
